# FloatSim — Simulador de Flotación de Arsenopirita Aurífera

Modelado cinético y optimización computacional de circuito rougher de tres celdas.

## Descripción
Simulador desarrollado en Python para modelar la cinética de flotación selectiva
de Au y As en arsenopirita aurífera. Incluye optimización de tiempos de residencia
y balance de masa por corriente.

## Tecnologías
- Python 3.12
- SciPy (odeint, minimize)
- NumPy, Matplotlib, Streamlit
